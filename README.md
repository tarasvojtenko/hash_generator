# 🔐 Hash Generator Pro — SHA‑512 и не только

> «Хешируй всё — от пароля до гигабайтного файла»

**Hash Generator Pro** — это набор консольных утилит для вычисления криптографических хеш-сумм (SHA‑1, SHA‑256, SHA‑384, SHA‑512, MD5).  
Программа умеет обрабатывать как короткие строки, так и большие файлы, выводя хеш в шестнадцатеричном или Base64-формате.

## 🚀 Особенности
- 🔢 Поддержка алгоритмов: **SHA‑1, SHA‑256, SHA‑384, SHA‑512, MD5** (по умолчанию **SHA‑512**).
- 📁 Чтение данных из файла (с потоковой обработкой для больших файлов).
- ✍️ Ввод строки прямо из командной строки или через STDIN.
- 🎨 Цветной вывод в терминале (зелёный — хеш, жёлтый — предупреждения).
- 📤 Экспорт результата в текстовый файл.
- 🔄 Поддержка нескольких форматов: **hex** (по умолчанию) и **base64**.
- ⚡ Прогресс-бар для больших файлов (где реализовано).
- 🧪 Проверка целостности — сравнение хеша с эталонным значением.

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости (в основном стандартные библиотеки или встроенные модули).

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | `hashlib` (встроенный), `argparse`   | `python hash_generator.py`              |
| Go         | стандартная библиотека               | `go run hash_generator.go`              |
| JavaScript | Node.js, `crypto` (встроенный)       | `node hash_generator.js`                |
| Java       | стандартная библиотека               | `javac hash_generator.java && java hash_generator` |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | `sha2`, `hex` (crates)               | `cargo run`                             |
| Ruby       | `digest` (встроенный)                | `ruby hash_generator.rb`                |
| PHP        | стандартная библиотека               | `php hash_generator.php`                |

> Все программы принимают следующие аргументы (единообразно, где возможно):
> - `--algo` или `-a` — алгоритм (sha512, sha256, sha384, sha1, md5)
> - `--format` или `-f` — формат вывода (hex, base64)
> - `--file` или `-F` — путь к файлу (если указан, хешируется содержимое файла)
> - `--output` или `-o` — файл для сохранения результата
> - `--compare` или `-c` — эталонный хеш для сравнения
> - `--help` — справка
